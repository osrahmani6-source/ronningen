Build a production-ready MVP web app for Rønningen Selskapslokale called “Rønningen Event Builder”.

Goal:
Create a modular B2B event quote system where customers and staff can build an event by selecting venue, food, transport, activities, and service. The system must automatically calculate a competitive final price while protecting Rønningen’s minimum margin.

Tech:

Next.js
TypeScript
Supabase/PostgreSQL
Tailwind CSS
Supabase Auth
Server-side pricing logic

Do not build payments or a full booking calendar yet.

Do NOT use fixed Basic / Standard / Premium packages.

Pricing types:

per_person

The pricing engine must:

Calculate list price
Calculate supplier/direct cost
Apply volume rules
Apply approved combination discounts
Check minimum margin
Calculate price per person
Compare price against configurable market target
Require manual approval if price or margin falls outside allowed limits

Never automatically reduce the price below the minimum profitable level.

IMPORTANT

Build the MVP around this principle:

Customer experience:
Simple modular event builder.

Internal system:
Supplier costs + pricing rules + margin protection + competitive pricing.

Do not hardcode prices directly in frontend components.

All prices, suppliers, margins, capacities, and rules must be editable through admin without changing code.

Build the MVP in this order:

Database and auth
Admin product/supplier management
Pricing engine
Employee quote builder
Customer event builder
Quote approval
Audit log
Mobile polish

Seed the system with example data so the full flow works immediately.
